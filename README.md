# DUMPERS PARADISE

Static multi-page ecommerce concept for the **DUMPERS PARADISE** streetwear brand, built around the **Hustlers Sacrifice** numbered drop.

## Notes
- The site is dark-mode-first and covers the full requested architecture: homepage, shop, product, drop/lookbook, SMS access, about, archive, size guide, shipping & returns, FAQ, contact, and journal.
- No external stock imagery is used.
- The image files inside `images/` are local placeholders clearly labeled for replacement with the user's own ChatGPT-generated visuals.

## Run locally
```bash
python -m http.server 8000
```
