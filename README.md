# DUMPERS NETWORK ARCHIVE

Premium streetwear storefront frontend built with Next.js App Router, TypeScript, Tailwind CSS, shadcn-style UI primitives, and Framer Motion.

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Included
- Full route scaffold for shop, collections, products, archive, lookbook, account, cart, and support pages.
- Local mock data for products, collections, archive entries, reviews, and lookbook frames.
- Reusable UI + layout components for a production-ready commerce frontend foundation.
